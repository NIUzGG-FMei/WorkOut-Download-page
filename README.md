## 这是什么 App

- **运动打卡**：按「日期 × 早/中/晚时段 × 训练项目」记录训练，一个时段可含多个项目。
- **恢复管理**：每个项目自定义恢复周期，实时显示「待训 / 恢复中」、剩余时间与进度；提前打卡会提示「注意休息」。
- **双日历**：月度记录（拳头=当日有打卡）+ 本周时段卡（红底白勾）。
- **成长记录**：按项目累计打卡次数与 11 档成长背景；本地头像与名称。
- **经验笔记**：记录训练心得，可关联多个项目，支持搜索筛选。
- **恢复提醒**（可选，默认关闭）：项目恢复完成时系统通知，锁屏只显示模糊文案。
- 开屏动画、深色模式、无障碍与「减少动效」适配。

## 隐私（重点）

- **完全没有网络权限**（`INTERNET`）：不联网、无账号、无云同步、无统计/广告/崩溃上报 SDK。
- 训练记录、笔记、头像**只保存在你的手机本机**（Room 数据库 + 应用私有目录）。
- 头像仅通过系统照片选择器读取你选中的那一张，存为私有副本，不动原图。
- 仅在开启提醒时用到 `通知` 与 `开机自启` 权限；锁屏通知不含具体项目名。

## 安装与升级

1. 下载 `WorkOut-1.0.0.apk` 到手机并点击安装；首次侧载需在弹窗中允许「安装未知来源应用」。
2. 升级时直接覆盖安装新版本即可，**本地数据完整保留**（同一签名）。
3. 首次安装如遇系统安全提示，属侧载应用常规提醒；请确认安装包来自本页面。
4. 通知提醒在「我的 → 消息通知」内手动开启；建议按应用内指引调整电池策略以保证提醒准时。
